# auto-reg 实测问题记录

记录时间：2026-08-23  
分支：`cursor/auto-reg-liao-encrypt-870c`  
环境：Debian 13 / Node 22 / Playwright Chromium（`chrome-headless-shell`）

## 1. 无头真实注册卡在 Turnstile

### 现象

```text
auto-reg register  count=1  dry-run=false  headed=false
  · init
  · identity
  · open_signup   （多次：加载补丁 / 注入脚本 / 打开注册页）
  · submit_profile
  …长时间无输出，或最终 FAILED stage=challenge / failed
```

邮箱分配（liao.bot `@bwen.net`）和挑战检测是通的；账号未写入 `accounts.json`。

### 根因

| 点 | 说明 |
|---|---|
| Playwright 无头二进制 | 默认启动 `chrome-headless-shell`，**不能加载 Chrome MV3 扩展** |
| 默认启动参数 | 自带 `--disable-extensions`，即便再传 `--load-extension=…/turnstilePatch` 也基本无效 |
| turnstilePatch 能力边界 | 只修 CDP 下 `MouseEvent.screenX/screenY`（指纹），**不是验证码求解器** |
| 卡住表象 | Turnstile 盖住 Continue 后，`page.click` 会一直等到 `timeoutMs`（最长 120s），看起来像死在 `submit_profile` |

vendor 里 cursor-auto-free / Cursor-Register 用 DrissionPage `add_extension` 加载的是**完整 Chrome**，和 Playwright 无头 shell **不是同一条路径**。

### 已做修复

- 无头：不再假装 `--load-extension`，只 `addInitScript` 注入 `script.js`，并打明确警告
- 有头（`--headed`）：`--load-extension` + `ignoreDefaultArgs: ['--disable-extensions']`
- `script.js` 改为 getter 形式（`clientX + offset`，含 `PointerEvent`），对齐 Xewdy444 / any-auto-register 的检测点
- Continue 点击改为短超时 + `noWaitAfter`，遇挑战尽快落到 `challenge` 失败，避免干等 120s

### 正确跑法

```bash
export PATH="$HOME/.local/node/bin:$PATH"
export AUTO_REG_VAULT_PASSWORD='你的口令'
cd /path/to/fly-cursor-free
npm run auto-reg -- register \
  --config packages/auto-reg/examples/config.example.json \
  --count 1 --headed
```

有头时扩展才会真正加载；若仍弹出 Turnstile，需在窗口里人工点击。无头下期望结果仍是 `CHALLENGE_REQUIRED`，属预期而非「补丁没拷进来」。

## 2. turnstilePatch 放哪、怎么加载

### 本仓库落地

```text
packages/auto-reg/resources/turnstilePatch/
  manifest.json
  script.js
  ORIGIN.txt
```

解析：`packages/auto-reg/src/engine/turnstile-patch.ts`  
接入：`packages/auto-reg/src/engine/browser.ts`  
配置：`turnstilePatch`（默认 `true`）

### vendor 对照（同源扩展，DrissionPage `add_extension`）

| 对照仓 | script.js | 谁加载 |
|---|---|---|
| `vendor/cursor-auto-free` | `turnstilePatch/script.js` | `browser_utils.py` |
| `vendor/wf-cursor-auto-free` | `turnstilePatch/script.js` | `browser_utils.py` |
| `vendor/cursor-auto-icloud` | `src/turnstilePatch/script.js` | `src/utils/browser_utils.py` |
| `vendor/cursor-auto-gui` | `resources/turnstilePatch/script.js` | `src/utils/browser_utils.py` |
| `vendor/cursor-free-vip` | `turnstilePatch/script.js` | `new_signup.py` |
| `vendor/zzxcursor` | `core/turnstilePatch/script.js` | `core/browser_manager.py`（另含自动点 checkbox，未采用） |
| `vendor/cursor-register` | `turnstilePatch/script.js` | `cursor_register.py`（权威对照，[JiuZX/Cursor-Register](https://github.com/JiuZX/Cursor-Register)） |

上游技术：

- https://github.com/TheFalloutOf76/CDP-bug-MouseEvent-.screenX-.screenY-patcher
- https://github.com/Xewdy444/CDP-bug-MouseEvent-.screenX-.screenY-patcher

`any-auto-register` 无该目录，同类逻辑写在 `platforms/cursor/browser_register.py`（`add_init_script` + 可选打码；AGPL，不可直接拷进本包）。

祖师爷对照仓：`chengazhen/cursor-auto-free` → 本仓库 `vendor/cursor-auto-free`。

## 3. 其它实测备注

| 项 | 说明 |
|---|---|
| Node | 系统常为 Node 20；auto-reg 需要 **≥ 22**（本机装在 `~/.local/node`） |
| 加密库 | 默认 `output.encrypt=true`，必须设 `AUTO_REG_VAULT_PASSWORD`；dry-run 也要 |
| 口令文件 | 本地可用 `.auto-reg-vault-password.local`（已加入 `.gitignore`），勿提交 |
| `accounts.json` | 已 gitignore；失败迭代不落盘 |
| CLI 日志 | 进度只打印 **stage 名**，不打印 message（防泄密）；因此连续多个 `open_signup` 是正常的 |

## 4. 仍未解决 / 已知断点

1. **无头自动过 Turnstile**：当前不做；需 `--headed` 或后续接可插拔打码（勿把「假点击扩展」写成唯一路径，见 `docs/AUTO_REG_MERGE_PLAN.md`）。
2. **手机 / radar 验证**：仍为硬失败 + 人工。
3. **选择器漂移**：注册页 DOM / WorkOS / Turnstile 变更时需改 `selectors`。
